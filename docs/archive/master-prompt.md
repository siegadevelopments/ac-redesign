====================================================
TECHNICAL REQUIREMENTS
====================================================

Follow the existing project's technology stack and conventions.

Before adding any dependency:

1. Check whether an existing dependency can solve the problem.
2. Prefer native CSS or existing utilities.
3. Keep the bundle lightweight.

Requirements:

- Fully responsive
- Mobile-first
- Accessible
- Keyboard navigable
- Semantic HTML
- Proper heading hierarchy
- WCAG-conscious contrast
- Respect prefers-reduced-motion
- Fast loading
- SEO-friendly
- No layout shifts
- Optimized images
- Proper metadata
- Open Graph metadata
- Structured data where appropriate

If using Next.js:

- Use server components where appropriate.
- Avoid unnecessary client components.
- Use next/image for images.
- Use next/font where appropriate.
- Follow App Router best practices if applicable.
- Generate metadata properly.

IMPLEMENTATION PROCESS
====================================================

Follow this sequence:

PHASE 1 — DISCOVERY

Inspect the repository.

Read:

- package.json
- README.md
- existing documentation
- app structure
- component structure
- styling configuration
- existing assets

Summarize your findings before major implementation.

PHASE 2 — PLAN

Create a concise implementation plan.

Identify:

- Components to reuse
- Components to create
- Files to modify
- Dependencies required, if any
- Potential risks

PHASE 3 — DOCUMENTATION

Create or update:

docs/project-context.md
docs/brand.md
docs/landing-page.md
docs/design-system.md
docs/development-guidelines.md

PHASE 4 — IMPLEMENTATION

Implement incrementally.

After each major section:

- Check responsiveness
- Check accessibility
- Check consistency
- Avoid duplicate code

PHASE 5 — QUALITY

Before completion:

- Run linting
- Run type checking
- Run tests if available
- Fix all introduced errors
- Review mobile layout
- Review desktop layout
- Check keyboard navigation
- Check reduced-motion behavior
- Check metadata

PHASE 6 — FINAL REPORT

Provide:

1. Summary of changes
2. Files created
3. Files modified
4. Any dependencies added
5. Remaining recommendations
6. Instructions for running the project

Do not declare the work complete if there are known errors.
